# Automating-Youtube-Shorts
Wanted a free and easy way for people to automate their YouTube shorts with the help of AI, which relies very little on manual inputs

# To create before starting
1. Create your own API key from Elevenlabs and insert it into tts.py
2. Using ElevenLabs create your own "Do you know voice?" voice, and save it as an MP3
3. Download a long-form, oddly satisfying video from YouTube

# How to use
1. Insert the do you know fact you want to add into the text output
2. Run the code in the following sequence:
   tts.py -> sub.py -> video.py -> combine.py
3. Results will be shown as success.mp4
